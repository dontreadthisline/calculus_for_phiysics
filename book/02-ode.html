2  常微分方程与动力学

第 1 讲末尾把胡克定律翻译成了 m\ddot{x} = -kx——定律变成了方程。本讲就是这道题的完整展开：方程的解长什么样、结构如何、初值条件扮演什么角色。物理定律几乎全部写成「变化率之间的关系」——牛顿第二定律、热力学、麦克斯韦（含时间那一半），所以这不是一道题，是一类题。计算技巧降到最低：读物理书要的是认出解的形状，不是亲手解。

Important本章路线：物理对象 → 数学缺口 → 工具落地

物理对象：随时间演化的系统——弹簧上的质点、放电的电容、衰减的放射性样品、被驱动的共振体。

数学缺口：定律给出的是「未知函数的变化率之间的关系」（如 m\ddot{x}=-kx），初等代数只能解未知数，不能解未知函数。

工具落地：常微分方程理论——解是一族含待定常数的函数，初值条件选出唯一解；线性方程有「齐次通解 + 特解」结构。掌握后可读受迫振动、共振、暂态与稳态，以及一切「演化」章节。

2.1 定律 → 方程

m\ddot{x} = F(x, \dot{x}, t) \qquad \text{牛顿第二定律：一个二阶常微分方程（ODE）} \tag{2.1}

「常」微分方程：未知函数 x(t) 只有一个自变量（时间）。(2.1) 不是拿来「代入求值」的公式——它的身份是关于未知函数的条件：找一个函数 x(t)，代入后它的二阶导数恰好等于 F/m。物理定律为什么总是这个形状？因为定律是局域的陈述：此刻的位置和速度决定此刻的加速度，下一步由下一步的定律接着管——「变化率驱动演化」是物理世界的基本约束关系。

「解方程」在 ODE 语境下意味着：找函数。这就是你在物理书里看到的 x(t) = A\cos(\omega t + \varphi_0) 的身份——它是方程 (2.3) 在 \gamma=f=0 情形的通解（牛顿第二定律作为 ODE 的展开见 (Taylor 2005, ch. 1)）。

2.2 降阶与状态空间：高阶方程的标准形式

求解之前，先做一次标准化。二阶方程 \ddot{x} = f(x, \dot{x}, t) 总能改写成两个一阶方程：把速度提升为独立变量 v = \dot{x}：

\dot{x} = v, \qquad \dot{v} = f(x, v, t)

把 (x, v) 合成一个状态向量，方程组说的是：状态的每个分量如何变化。这是高阶方程的通用标准形式（n 阶 \Leftrightarrow n 维状态空间中的一阶系统），两个直接收益：

  1. 数值模拟只认一阶。物理引擎与 N 体模拟器（RK4 等数值积分器）内部全是「状态向量 + 一阶右端函数」——你写过的任何游戏物理循环，本质都是这个形式。
  2. 解 = 状态空间中的轨迹。解不再是一条 x(t) 曲线，而是 (x, v) 平面（相平面）上的一条轨道；稳定性、吸引子这些「动力学系统」语言全部住在这里——本讲末尾的相图就是状态空间的几何表示（状态空间方法的系统训练：(Strogatz 2015, chs. 5-6)）。

2.3 一阶方程：指数解

最简单的 ODE 族里，两个成员覆盖了物理书的大半入门场景。

可分离变量：\frac{\mathrm{d}y}{\mathrm{d}t} = g(y)\,h(t)。变量除法把导数拆开、两边各自积分（第 1 讲的积分运算）。原型是放射性衰变：

\frac{\mathrm{d}N}{\mathrm{d}t} = -\lambda N \;\;\Longrightarrow\;\; N(t) = N_0\, e^{-\lambda t} \tag{2.2}

读法：衰变率正比于现存数量——越多衰得越快，于是指数衰减。「变化率的值正比于当前的值」⇒ 指数解，这是全书最值得记住的一条定性规律（电容放电、牛顿冷却、光吸收全是它；分离变量与一阶方程的教材定位：(Stewart 2016, ch. 9)）。

一阶线性：\frac{\mathrm{d}y}{\mathrm{d}t} + P(t)\,y = Q(t)。有个万能的积分因子技巧，本书不讲——你只需认出形状与解的定性图像：暂态（齐次部分衰减掉）+ 稳态（跟着外源走），见下文「结构」一节。

初值条件：注意 (2.2) 里的 N_0——方程本身没有固定它。通解是函数族，初值负责选出其中一个。一阶方程需要一个初值（N(0)=N_0）。

2.4 二阶常系数：谐振子

力学与电路的骨干方程：

\ddot{x} + \gamma\,\dot{x} + \omega_0^2\, x = f(t) \qquad (\text{自由振动 } \gamma=f=0;\; \text{阻尼 } \gamma>0;\; \text{受迫 } f\neq 0) \tag{2.3}

它来自弹簧 m\ddot{x} = -kx（加上阻尼、外力），覆盖单摆小角度、LC 电路、分子振动、桥梁、地震仪。怎么解不重要，为什么解法有效值得看一眼——一行就够：猜 x = e^{rt}，因为指数函数求导后形状不变（\frac{\mathrm{d}}{\mathrm{d}t}e^{rt} = r\,e^{rt}，比例因子只乘在前面），代入后 e^{rt} 从方程里约掉，剩下一个代数方程：

r^2 + \gamma\, r + \omega_0^2 = 0 \qquad \text{（特征方程）} \tag{2.4}

二阶 ODE 降成二次方程，根 r_{1,2} 给出两个解 e^{r_1 t}, e^{r_2 t}。判别式分三种情形，每种对应一种看得见的运动：

判别式 根 解的形状 物理名字
\gamma^2 < 4\omega_0^2 共轭复根 -\gamma/2 \pm i\omega' e^{-\gamma t/2}\cos(\omega' t + \varphi_0) 欠阻尼：振荡着衰减
\gamma^2 = 4\omega_0^2 重根 (A + Bt)\,e^{-\gamma t/2} 临界阻尼：不振荡，最快归位（门吸、仪表指针）
\gamma^2 > 4\omega_0^2 两负实根 A e^{r_1 t} + B e^{r_2 t} 过阻尼：缓慢爬回（浓糖浆里的弹簧）

复根怎么给出振荡？欧拉公式 e^{i\theta} = \cos\theta + i\sin\theta——复指数的实部就是振荡（复数与欧拉公式的系统处理：(Boas 2006, ch. 2)）。「振荡 = 频率取虚数的指数」，虚数不是玄学，是特征方程在告诉你「这个系统在振动」。

结构定理（线性 ODE 的组织方式，物理书的地基）：

y_{\text{通解}} = y_h \;(\text{齐次通解，含待定常数}) + y_p \;(\text{任一特解}) \tag{2.5}

齐次部分 y_h 是系统自身的运动模式（自然频率、衰减率），特解 y_p 是外源驱动的响应。受迫振动的标准图像由此读出：刚启动时两者都在（暂态），阻尼磨掉 y_h 后只剩 y_p（稳态）；外源频率逼近 \omega_0 时 y_p 的振幅暴涨（共振）。读 RLC 电路、受迫振动、散射共振，全是这一个结构（受迫振动与共振的展开：(Taylor 2005, ch. 5)）。

为什么解可以叠加以至「通解 = 齐次 + 特解」？把 (2.3) 的左端写成一个线性微分算子：

L \;\equiv\; \frac{\mathrm{d}^2}{\mathrm{d}t^2} + \gamma\,\frac{\mathrm{d}}{\mathrm{d}t} + \omega_0^2, \qquad L[x] = f(t)

「线性」指的是 L 的性质：L[\alpha x + \beta y] = \alpha L[x] + \beta L[y]（求导本身线性、系数固定）。于是解的线性组合还是解——二阶齐次方程的解构成一个二维线性空间（维数 = 阶数），e^{r_1 t} 与 e^{r_2 t} 是一组基，通解就是全空间。线性从哪来？定律本身线性（弹簧力 \propto 位移）。非线性 ODE（如大角度单摆）没有这个结构，解也不可叠加——物理书对它们的态度通常是「小角度近似线性化」（第 1 讲的局部线性近似再次出场）。

初值条件：二阶方程需要两个（如 x(0) 与 \dot{x}(0)：初始位置与初始速度）。直觉：预测未来需要知道「现在在哪 + 现在往哪走」，缺一不可。通解里恰好有两个待定常数，两个条件恰好锁定它们——这不是巧合，是「阶数 = 所需初值个数」的一般规律。

图 2.1 演出「解族 + 初值选解」的几何图像：背景短刻度是方向场（每个点上方程规定的斜率），曲线族是解族（每条对应一组待定常数），琥珀点是初值——过每个初值点恰好有一条解曲线，这就是「初值条件从解族中选出唯一解」。

2.5 定性分析：不解也读得出

物理书大量出现「不解方程，直接判断」的段落，工具是相图：以 (x, \dot{x}) 为坐标画轨迹族——相平面就是前文的状态空间，相图是状态空间中轨迹族的图像（定性方法的系统训练：(Strogatz 2015, ch. 2)）。两个够用的读法：

  • 平衡点（F=0 的点）：附近轨迹被推开的 = 不稳定（倒立摆）；被吸住的 = 稳定（碗底）。\frac{\mathrm{d}}{\mathrm{d}t}（能量）< 0 恒成立的系统必然滑向平衡（阻尼耗散）。
  • 轨道不交叉：相图轨迹互不相交（同一初值只有一个未来——决定论）。

2.6 耦合方程组一瞥

两个自由度互相影响（两节车厢挂弹簧、双摆小角度）时，得到方程组：\ddot{x}_1 依赖 x_1, x_2。线性代数登场：找简正模式——两个特殊「步调」，各以固定频率同步振动；一般运动 = 模式的叠加（把矩阵对角化的物理名字）。读到「简正模式」「本征频率」时认出它：这是矩阵本征值问题在力学中的形式，第 10 讲它还会以分离变量的身份回来（简正模式的教学展开：(Taylor 2005, ch. 11)）。

Note判据 F（见微分方程）三连问
  1. 几阶？ 最高导数阶数 = 需要的初值/边界条件个数。
  2. 线性吗？ 线性 ⇒ 解可叠加（y_h + y_p、模式分解全合法）；非线性 ⇒ 只能定性或数值。
  3. 齐次吗？ 有外源（非齐次）⇒ 解 = 自由衰减的模式 + 被驱动的稳态响应。

2.7 本章小结

  • 定律 = 变化率的局域关系，写下来就是 ODE；解是函数族，初值选出唯一成员。
  • 「变化率正比于当前值」⇒ 指数；「回复力」⇒ 振荡（复特征根）；两者都在说特征方程。
  • 结构定理 y = y_h + y_p 是受迫振动、共振、暂态/稳态的统一读法。
  • 二阶要两个初值（位置 + 速度）；相图不解方程也能读出稳定性。

方程的解——无论 x(t) 还是完整的空间轨迹 \mathbf{r}(t)——都是曲线。曲线有自己的几何学：切向朝哪、弯得多急、加速度怎么分解。下一讲把轨迹当作几何对象来读，那是力学书运动学章节的全部基础。
