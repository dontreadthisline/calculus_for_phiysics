3  参数方程与空间曲线

第 2 讲的解 x(t) 只是一维的数。完整的运动是 \mathbf{r}(t)——空间中的一条曲线：轨道是它，轨迹是它，弹簧振子的往复、行星的椭圆、带电粒子在磁场里的螺旋，全是它。本讲把轨迹当作几何对象来读：它朝哪（切向）、弯得多急（曲率）、加速度怎么沿几何方向分解。这是力学书运动学章节的全部基础。

Important本章路线：物理对象 → 数学缺口 → 工具落地

物理对象：空间中运动的质点——行星的椭圆轨道、磁场中的螺旋线、弹簧振子的往复直线。

数学缺口：轨迹是三维向量值函数 \mathbf{r}(t)，一元导数只定义在数值函数上；「轨迹弯得多急」也没有现成的量度。

工具落地：向量值函数的微分：速度、加速度；单位切向量与曲率 \kappa=1/\rho；加速度的切向/法向分解 \mathbf{a}=\dot v\hat{\mathbf{T}}+(v^2/\rho)\hat{\mathbf{N}}——向心加速度 v^2/R 由此得到完整推导。

3.1 参数曲线：轨迹、参数化、运动规律

描述曲线最强的办法不是解方程（x^2+y^2=1 只告诉你点集），而是引入一个跑动的参数——通常就是时间：

\mathbf{r}(t) = \big(x(t),\; y(t),\; z(t)\big) \tag{3.1}

这里有三层东西，物理书随时在三者之间切换，认出层次就不迷路：

层次 是什么 例子
轨迹 纯点集，无先后 「椭圆」这个几何对象
参数化 点集 + 走法（哪个参数值对应哪个点） (\cos\theta, \sin\theta) 与 (\cos 2\theta, \sin 2\theta) 同一圆，走法不同
运动规律 物理参数化：参数是时间，含快慢 匀速圆周 vs 变速圆周，轨迹相同

几何量（切向、曲率）只依赖轨迹与参数化的方向，物理量（速率、加速度大小）依赖运动规律——力学书说「换成弧长参数化」时，就是在把几何与物理分层（教材定位：(Stewart 2016, ch. 13)）。

3.2 位置、速度、加速度

运动学全部内容就是这条曲线的一二阶导数：

\mathbf{v} = \frac{\mathrm{d}\mathbf{r}}{\mathrm{d}t} = \dot{\mathbf{r}} \quad(\text{切向量，方向即运动方向}), \qquad \mathbf{a} = \ddot{\mathbf{r}} \tag{3.2}

读法：速度是一个向量——「这一瞬间朝哪、多快」。速率是它的长度 |\mathbf{v}|。加速度还是它的导数，即使速率不变、方向在变，加速度也不为零（圆周运动的向心加速度就是纯方向变化的加速度——本讲末尾将给出它的完整来历）。

位移与路程是两个量：位移是向量 \Delta\mathbf{r} = \mathbf{r}(t_2)-\mathbf{r}(t_1)（直线距离 + 方向），路程是标量——沿途真实走过的总长。一小段时间内两者几乎相等，但累积起来可以差很远：绕操场一圈，位移为零，路程 400 米。路程的微元就是速率乘时间（勾股定理的无穷小版）：

\mathrm{d}s = |\mathbf{v}|\,\mathrm{d}t, \qquad s = \int_{t_0}^{t_1} |\mathbf{v}(t)|\,\mathrm{d}t \tag{3.3}

弧长积分几乎永远积不出闭式，物理书毫不在意——重要的是语义：路程 = 速率对时间的累积（第 1 讲判据 B 的直接应用；弧长公式见 (Stewart 2016, sec. 13.3)）。

3.3 切向量与曲率：轨迹的两个几何量

速度 \mathbf{v} 混合了「方向」与「快慢」。把方向单独提出来——单位切向量：

\hat{\mathbf{T}} = \frac{\mathbf{v}}{|\mathbf{v}|} \qquad \text{（长度恒为 1，只管朝向）} \tag{3.4}

轨迹的第二个内禀几何量问：弯得多急。\hat{\mathbf{T}} 是方向指针，弯曲使指针随走过的路程转动——转得越快，弯得越急。于是定义曲率为方向对弧长的变化率的大小：

\kappa = \Big|\frac{\mathrm{d}\hat{\mathbf{T}}}{\mathrm{d}s}\Big|, \qquad \rho = \frac{1}{\kappa}\;\text{（曲率半径）} \tag{3.5}

两个锚点：直线不转，\kappa = 0、\rho = \infty；半径 R 的圆走一圈（\Delta s = 2\pi R）方向整整转一圈（\Delta\varphi = 2\pi），\kappa = 2\pi/2\pi R = 1/R、\rho = R——曲线一点处的弯曲与半径 \rho 的圆弧互换，二阶以内分不出差别（曲率半径就是当地等效圆的半径；曲率的系统处理：(Stewart 2016, sec. 13.3)）。

加速度的分解（下一节）真正要用的，是 (3.5) 的向量形式。两个事实各一行：

  • 方向：\hat{\mathbf{T}} 长度恒为 1，即 \hat{\mathbf{T}}\cdot\hat{\mathbf{T}} = 1。两边对 s 求导：\hat{\mathbf{T}}\cdot\frac{\mathrm{d}\hat{\mathbf{T}}}{\mathrm{d}s} = 0——内积为零，即导数垂直于 \hat{\mathbf{T}}（长度恒定的箭头只能转，箭尖贴单位圆运动，其速度沿圆的切向）。垂直方向有两个，取指向轨迹凹侧的那支，记作 \hat{\mathbf{N}}（主法向量）。
  • 大小：即 \kappa——(3.5) 的定义本身。

方向与大小合成一条向量关系，曲率的全部内容就是它：

\boxed{\;\frac{\mathrm{d}\hat{\mathbf{T}}}{\mathrm{d}s} \;=\; \kappa\,\hat{\mathbf{N}} \;=\; \frac{1}{\rho}\,\hat{\mathbf{N}}\;}

下一节推导加速度时，把这条关系直接代入即可——不需要任何新的论证。

3.4 加速度的几何分解：变速 + 转弯

为什么沿 \hat{\mathbf{T}}、\hat{\mathbf{N}} 分解？加速度是个向量，在直角坐标里拆成 a_x, a_y——但这两个数没有物理身份：x 方向不代表任何动力学角色。力学问题真正关心的是两类力：沿轨道推动的（引擎牵引、摩擦、重力沿轨道的分量）与垂直轨道约束的（绳的张力、轨道的正压力）。沿 \hat{\mathbf{T}}（轨道方向）与 \hat{\mathbf{N}}（垂直轨道、指凹侧）分解，两个分量恰好逐一对应这两类力——这就是力学书「自然坐标系」的全部含义，也是这个分解存在的理由。

推导三行（记 v = |\mathbf{v}|——速率，标量；\mathbf{v} 是向量，v 是它的长度）。\mathbf{v} = v\,\hat{\mathbf{T}}（(3.4) 移项），对时间求导：

  1. 乘积法则：\mathbf{a} = \dot{v}\,\hat{\mathbf{T}} + v\,\dfrac{\mathrm{d}\hat{\mathbf{T}}}{\mathrm{d}t}——第一项已经就是变速分量；
  2. 链式法则（用弧长微元 \mathrm{d}s = v\,\mathrm{d}t，式 (3.3)）：\dfrac{\mathrm{d}\hat{\mathbf{T}}}{\mathrm{d}t} = \dfrac{\mathrm{d}\hat{\mathbf{T}}}{\mathrm{d}s}\cdot v；
  3. 代入上节的向量关系 \dfrac{\mathrm{d}\hat{\mathbf{T}}}{\mathrm{d}s} = \dfrac{1}{\rho}\hat{\mathbf{N}}：

\mathbf{a} \;=\; \underbrace{\dot{v}\,\hat{\mathbf{T}}}_{\text{变速（沿轨道）}} \;+\; \underbrace{\frac{v^2}{\rho}\,\hat{\mathbf{N}}}_{\text{转弯（垂直轨道）}} \tag{3.6}

完毕。v^2 里两个 v 的来历不同（一个来自链式法则、一个来自乘积法则的前因子）：速率加倍时每秒转过的角度大一倍、速度本身的尺度也大一倍——所以转弯加速度与速率平方成正比。

这个分解买到什么（每个都是物理书的常用件）：

  • 向心加速度的完整来历：匀速圆周 \dot v = 0、\rho = R，(3.6) 给出 \mathbf{a} = v^2/R 指向圆心。牛顿第二定律沿法向一写：垂直方向的合力 = mv^2/R——绳张力、卫星引力、拱桥正压力全用它。水平弯道的限速标志就是它：摩擦提供向心力有上限 \mu m g \le m v^2/R，得 v_{\max} = \sqrt{\mu g R}。
  • 约束问题一题两方程：单摆沿绳方向与轨道切向分别写牛顿第二定律——切向 m\dot v = -mg\sin\theta（驱动运动），法向 \text{张力} - mg\cos\theta = mv^2/L（张力）——一个方程管运动、一个方程管约束力，互不纠缠。珠子在弯管里、车过拱桥，全是这个写法。
  • 匀速直线两项全零——牛顿第一定律是 (3.6) 的退化情形。

图 3.1 演出这套几何：质点沿轨迹运动（光点），采样点上画出单位切向 \hat{\mathbf{T}}（绿，恒指运动方向）、主法向 \hat{\mathbf{N}}（琥珀，恒指凹侧）与加速度 \mathbf{a}（灰）。观察两件事：\hat{\mathbf{N}} 永远指向凹侧；\mathbf{a} 总在 \hat{\mathbf{T}} 与 \hat{\mathbf{N}} 张成的扇区内——它就是两份贡献的向量和。

（运动学分解的教材展开：(Stewart 2016, sec. 13.4; Taylor 2005, ch. 1)。）

Note判据 C1（读运动学）

看到轨迹问题先分层：问的是几何（切向、曲率——只依赖轨迹）还是物理（速率、加速度——依赖运动规律）？看到 v^2/\rho 立即翻译成「转弯加速度」；看到「向心」立即想 v^2/R 是 (3.6) 的特例。

3.5 本章小结

  • 轨迹是点集，参数化是走法，运动规律是物理参数化——几何量与物理量由此分层。
  • 位移与路程是两个量；路程微元 \mathrm{d}s = |\mathbf{v}|\,\mathrm{d}t。
  • 曲率 \kappa = 单位路程转过的方向；\rho = 1/\kappa 是当地等效圆半径。
  • \mathbf{a} = \dot v\,\hat{\mathbf{T}} + \dfrac{v^2}{\rho}\,\hat{\mathbf{N}}：加速度 = 变速 + 转弯，向心加速度拿到完整来历。

运动学语言已能描述任何轨迹——但描述位置时我们一直在偷偷用「直角坐标」。行星轨道的问题立刻暴露不便：力永远指向原点，而 x,y 都在变。自然的描述方式是「离原点多远 + 朝哪个方向」——这就把坐标系本身推到了前台。下一讲：曲线坐标，以及随位置变化的基向量。
